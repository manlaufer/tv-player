# TV Player

A fast, sleek, living-room desktop media and live TV player designed for big screens, remote controls, and effortless couch navigation.

---

## Key Features

- **Live TV & Playlists**  
  Load M3U/M3U8 playlists from a URL or local file, or sign in with Xtream Codes. Browse smart channel categories, search instantly, and switch channels directly with `0–9` number keys.

- **Built-In TV Guide (EPG) & Catch-Up**  
  Automatic TV schedule discovery with a live Now/Next program bar, a full-screen interactive TV Guide (`G`), program reminders, and 7-day Catch-up replay on supported channels.

- **Movies, Series & Favorites**  
  Dedicated browsing tabs for Live TV, Movies, Series (organized by seasons and episodes), Recently Watched, and custom Favorites folders.

- **Telegram Media Streaming**  
  Quick QR-code sign-in from your phone (`Telegram -> Settings -> Devices -> Link Desktop Device`) to browse and stream videos directly from your subscribed Telegram channels.

- **Home Network Folders**  
  Connect local folders or shared home network drives to watch your personal video collection from one unified interface.

- **Subtitles, Audio Tracks & Recording**  
  Switch between audio languages and subtitle tracks on the fly, load external `.srt` or `.vtt` subtitle files with timing adjustment, schedule or start one-click DVR recordings, and protect content with a Parental PIN.

- **10-Foot Living-Room Experience**  
  Dark cinema interface with auto-hiding on-screen controls, split-screen program guide, and full keyboard, remote control, and gamepad navigation.

---

## Quick Start

1. **Download `TV-Player-Setup.exe`** from the **Releases** tab and run the installer.
2. **Launch TV Player** to open in fullscreen living-room mode.
3. **Press `S` (Setup)** to add your playlist URL/file, connect a home network folder, or scan the Telegram QR code to start watching.

---

## Everyday Controls

| Key / Button | Action |
| :--- | :--- |
| `Up` / `Down` / `Left` / `Right` | Navigate menus, channels, and guide |
| `Enter` | Select / Play |
| `0–9` | Jump directly to a channel number |
| `G` | Open TV Guide (EPG) |
| `S` | Open Setup |
| `Space` | Play / Pause |
| `F` or `F11` | Toggle Fullscreen |
| `Escape` | Back / Close menu |
